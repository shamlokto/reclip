Get Started

Up in 60 seconds

Two paths: run it locally with a shell script, or containerise with Docker.

1
Install dependencies
Make sure yt-dlp, ffmpeg, and Python 3.8+ are installed.
# macOS
brew install yt-dlp ffmpeg

# Ubuntu / Debian
sudo apt install ffmpeg && pip install yt-dlp
2
Clone and run
Clone the repo and launch with the included shell script.
git clone https://github.com/averygan/reclip.git
cd reclip
./reclip.sh
3
Open in browser
ReClip is now running at http://localhost:8899. Paste a URL and start downloading.
1
Build the image
git clone https://github.com/averygan/reclip.git
cd reclip
docker build -t reclip .
2
Run the container
docker run -p 8899:8899 reclip
3
Open in browser
Visit http://localhost:8899. To persist downloads, mount a volume: -v $(pwd)/downloads:/app/downloads
